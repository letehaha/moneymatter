MoneyMatter has an MCP server. MCP (Model Context Protocol) is the standard way AI assistants such as Claude and ChatGPT connect to other apps. Once connected, you can ask the assistant about your money in plain language, and let it add or fix records if you allow that.

The assistant signs in through MoneyMatter itself. You never paste a password or an API key into it.

## What you need

- A MoneyMatter account. The MCP server is included in every plan and in the free trial.
- An AI app that can add a remote MCP server by URL. This page covers Claude, ChatGPT and Claude Code.
- The MoneyMatter MCP address:

  ```
  https://mcp.moneymatter.app/mcp
  ```

A self-hosted MoneyMatter has its own address. See [Self-hosted MoneyMatter](#self-hosted-moneymatter).

## Find the address in the app

<Steps>

1. Click the gear button (**Settings**) at the top right of the app.
2. Under **Workspace**, choose **AI**.
3. Open the **Connectors (MCP)** tab.

</Steps>

The **MCP Server** section shows the address with a copy button. Under **Quick Connect**, **Open Settings** takes you to the right page in Claude or ChatGPT, and the arrow next to it shows short steps. **Active connectors** lists every app that has access.

## Connect Claude

This works in Claude on the web, in the Claude desktop app and in the mobile apps. You add the connector once and it's available in all of them.

<Steps>

1. In Claude, open **Customize**, then **Connectors**, or go straight to [claude.ai/customize/connectors](https://claude.ai/customize/connectors).
2. Click **Add custom connector**. In some accounts you click **+ Add** first.
3. Enter a name, for example `MoneyMatter`.
4. In the server URL field, paste `https://mcp.moneymatter.app/mcp`.
5. If Claude asks how to sign in, choose **Sign in now**. Leave the other options as they are.
6. Click **Add**.
7. If the connector shows a **Connect** button, click it.
8. MoneyMatter opens in your browser. Sign in if asked, choose what Claude may do, then click **Approve**. See [Choose what the assistant can do](#choose-what-the-assistant-can-do).

</Steps>

To use it, start a chat, click **+** in the message box, choose **Connectors** and turn MoneyMatter on.

<Aside type="note" title="Plans and work accounts">
  Claude's Free plan allows one custom connector. In a Team or Enterprise
  organization, only an owner can add a custom connector, under **Organization
  settings**, then **Connectors**. Everyone else then finds it under
  **Customize**, then **Connectors**, and clicks **Connect**.
</Aside>

Claude's own guide: [Get started with custom connectors using remote MCP](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Connect ChatGPT

Use ChatGPT on the web for the setup.

<Steps>

1. Open [chatgpt.com/plugins](https://chatgpt.com/plugins).
2. Click the plus button, then **Add custom MCP server**.
3. Enter a name, for example `MoneyMatter`.
4. Under **Connection**, paste `https://mcp.moneymatter.app/mcp` as the **Server URL**.
5. For authentication, choose **OAuth**.
6. Read the warning and select **I understand and want to continue**.
7. Click **Create as a plugin**.
8. MoneyMatter opens in your browser. Sign in if asked, choose what ChatGPT may do, then click **Approve**.
9. Check the list of tools ChatGPT found, then install the plugin.

</Steps>

To use it, start a new chat, type `@` and pick MoneyMatter.

<Aside type="caution" title="ChatGPT's setup depends on your plan">
  OpenAI has changed this screen several times, and it can look different in
  your account. Depending on your plan or workspace you may need to turn on
  Developer mode first, and some plans let a custom MCP server read your data
  but not change it. OpenAI's pages have the current rules: [Developer mode and
  MCP apps in
  ChatGPT](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt)
  and [the setup
  guide](https://developers.openai.com/api/docs/guides/custom-mcp-server).
</Aside>

ChatGPT asks you to confirm before it runs a tool that changes data.

## Connect Claude Code

<Steps>

1. In your terminal, run:

   ```bash
   claude mcp add --transport http moneymatter https://mcp.moneymatter.app/mcp
   ```

   Add `--scope user` to make it available in every project, not only the current one.

2. Start `claude` and run `/mcp`.
3. Select `moneymatter`, press Enter and choose **Authenticate**.
4. MoneyMatter opens in your browser. Sign in if asked, choose what Claude Code may do, then click **Approve**.

</Steps>

Until you finish step 4, `claude mcp list` shows the server as needing authentication. That's expected.

## Other AI apps

Any app that supports remote MCP servers with OAuth sign-in can connect. Add a server with the address `https://mcp.moneymatter.app/mcp`, and the app sends you to MoneyMatter to approve access. The full list of tools is in the [server card](https://moneymatter.app/.well-known/mcp/server-card.json).

## Choose what the assistant can do

Before an app gets access, MoneyMatter shows a page titled "[app name] wants access to your MoneyMatter data". It has two steps: **Permissions**, what the app may do, and **Tools**, what it can work with.

### Permissions

The first step lists the permissions the app asked for. You can turn two of them on or off:

  hint="Mock GET /auth/oauth2/client-info to return the name Claude, then open /oauth/authorize?client_id=x&redirect_uri=https://claude.ai/cb&scope=finance:read finance:write finance:delete profile:read offline_access. Crop to the card."
/>

| Permission                              | On this page                                 | What it allows                                                                |
| --------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| **View your financial data**            | **Always granted**                           | Read accounts, transactions, budget plans, loans, currencies, portfolios and stats. |
| **Create and edit your financial data** | **Optional**, ticked when the page opens     | Add and update transactions, budget plans, subscriptions, loans, investments and more. |
| **Delete your financial data**          | **Optional**, not ticked when the page opens | Permanently remove records, such as transactions, accounts or payees.         |
| **View your profile**                   | **Always granted**                           | See your name, email and base currency.                                       |
| **Stay connected in the background**    | **Always granted**                           | Keep access without asking you to approve again each session.                 |

Click **Continue** to pick the tools, or **Deny** to cancel.

For questions and reports only, untick **Create and edit your financial data** before you approve. The assistant can then read your data but can't change anything.

<Aside type="caution" title="Deleting can't be undone">
  Tick **Delete your financial data** only for an app you fully trust. A deleted
  record is gone for good.
</Aside>

### Tools

The second step picks which sets of tools the app gets. **Core** is always on. Every other set is off when the page opens; tick the ones you want, or use **Add all** and **Core only**. Click **Approve** to connect, or **Back** to return to the permissions.

The app loads every tool you pick into each chat, so pick only what you use. The counter at the bottom shows how many tools you picked. ChatGPT and VS Code Copilot load at most 128 tools, and the counter warns you when you go over that. Claude and Claude Code have no such limit.

| Set                      | Scope                      | What it covers                                                                                   |
| ------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------ |
| **Core**                 | none, always on            | Accounts, transactions, transfers and refunds, attachments, categories, tags, payees and reports. |
| **Recurring payments**   | `toolset:subscriptions`    | Recurring payments, their periods and candidates, and planned transactions.                       |
| **Budget plans**         | `toolset:budget-plans`     | Budget plans with their groups, lines and line goals, and savings goals.                          |
| **Trackers**             | `toolset:trackers`         | Spending trackers, their lines and suggestions.                                                   |
| **Automations**          | `toolset:automations`      | Transaction rules, payee aliases, ignored payee names and tag reminders.                          |
| **Review and cleanup**   | `toolset:review`           | Refund and transfer matches, duplicate cleanup and stuck pending transactions.                    |
| **Groups and templates** | `toolset:groups-templates` | Transaction groups and transaction templates.                                                     |
| **Investments**          | `toolset:investments`      | Portfolios, holdings, securities, investment transactions and portfolio transfers.                |
| **Ventures**             | `toolset:ventures`         | Venture platforms, deals and events.                                                              |
| **Loans and vehicles**   | `toolset:loans-vehicles`   | Loans with their payments and notes, and vehicles.                                                |
| **Currencies**           | `toolset:currencies`       | Your currencies and exchange rates.                                                               |
| **Imports and sharing**  | `toolset:imports`          | Import batches, bank connections and who you share with, read only.                               |

The [server card](https://moneymatter.app/.well-known/mcp/server-card.json) lists every tool with the set it belongs to.

An app connected before tool sets existed has **Core** only. To add more, [revoke the app](#disconnect-an-app) and connect it again.

### Change what you approved

To change the permissions or the tools later, [revoke the app](#disconnect-an-app) and connect it again.

If your account is in [read-only mode](/settings/plans-and-billing/#read-only-mode), a connected assistant can still read your data, but every change it tries is refused, whatever you approved.

## What you can ask

With the tool sets for them, the assistant can work with:

- accounts;
- transactions, including planned ones, refunds, transfers and attachments;
- categories, tags and tag reminders;
- payees;
- trackers, budget plans and savings goals;
- subscriptions, automation rules and transaction templates;
- loans and vehicles;
- currencies and exchange rates;
- investments and venture deals;
- reports, such as spending, cash flow and net worth.

Some things to try:

- "Compare my dining out spending this month to my 3-month average."
- "Which of my subscriptions got more expensive this year?"
- "Show every transaction over $100 last quarter that wasn't a subscription."
- "What's my average weekly grocery spend, and how has it changed?"
- "I want to save $500 a month. Where could I realistically cut?"
- "Am I on track for my holiday goal? What would I need to save each month to get there by June?"
- "How much of my budget plan is left in groceries this month, and how did it go over the last three months?"
- "When will my car loan be paid off, and how much interest is left?"
- "Find duplicate transactions from last month's bank sync."

With edit access you can also ask it to do things, for example:

- "Categorize last week's uncategorized transactions."
- "Create a tracker of $400 for groceries this month."
- "Confirm my rent payment, it went out today."

<Aside type="note" title="Budget versus tracker">
  The **Budget** page in the app is a budget plan: money you assign to
  categories period by period, see [Start budgeting](/budgeting/start-budgeting/).
  A **tracker** is a spending limit on some categories over a date range. Say
  which one you mean if the assistant mixes them up. The assistant can only
  change a budget if your plan [includes budgeting](/budgeting/start-budgeting/#which-plans-include-budgeting).
</Aside>

While you change your base currency, MoneyMatter recalculates your history and blocks edits until it finishes. The assistant's changes are refused during that time, and it can still read. Ask it again once the change is done.

### What the assistant can't do

Some things stay in the app, and the assistant can't do them even with every permission:

- Connect or disconnect a bank, and sync a bank connection. It can show the state of your connections and syncs.
- Share an account or budget with someone, or accept or change a share. It can show who has access.
- Import a file, or download or back up your data. It can list your past imports and undo one.
- Change the AI settings, such as AI providers and API keys.
- Manage account groups, notifications or your app settings, or change your base currency.
- Change your password or sign-in, manage your subscription and billing, or delete your account.
- Revoke its own access. You do that under [Disconnect an app](#disconnect-an-app).

### Goals

The assistant sees your [goals](/goals/overview/) with their progress: saved, left, pace, projected finish, monthly need and status. With edit access it can create a goal, change it, and pause, archive or restore it. Deleting a goal needs **Delete your financial data**. Creating, changing and deleting goals also need goals on your plan or a running goals trial. The tools are `get_goals`, `create_goal`, `update_goal` and `delete_goal`, in the **Budget plans** set.

## Disconnect an app

<Steps>

1. Open **Settings**, choose **AI**, then the **Connectors (MCP)** tab.
2. Under **Active connectors**, find the app. Each one shows when it was connected, when it was last used and what it's allowed to do.
3. Click **Revoke**, then confirm with **Revoke Access**.

</Steps>

## Self-hosted MoneyMatter

A self-hosted MoneyMatter runs its own MCP server, and nothing goes through moneymatter.app.

- Set `MCP_BASE_URL` on your server. The [environment reference](https://github.com/letehaha/moneymatter/blob/main/self-hosting/docs/environment-reference.md) explains which value to use.
- Use the address shown under **Settings**, **AI**, **Connectors (MCP)** in your own install in place of `https://mcp.moneymatter.app/mcp`.
- Claude and ChatGPT connect from their own servers, so your install has to be reachable from the internet over HTTPS. Claude Code connects from your computer.

## If something goes wrong

- **The assistant says it can't change or delete something.** You didn't grant that permission, or your account is in read-only mode. Revoke the app and connect it again with the permission ticked.
- **The assistant says it has no tool for something.** The tool is in a set you didn't pick, such as **Investments** or **Budget plans**. Revoke the app and connect it again with that set ticked.
- **You can't add a connector in Claude at work.** Ask an owner of your organization to add it.
- **You need to change how a Claude connector signs in.** Claude doesn't let you edit that. Remove the connector and add it again.
- **Claude Code doesn't return from the browser after you approve.** Copy the full address from the browser's address bar and paste it into the prompt Claude Code shows.
